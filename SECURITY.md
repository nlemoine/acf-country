# Security policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | Yes                |
| 3.x     | Security fixes only |
| < 3.0   | No                 |

## Reporting a vulnerability

Do not report vulnerabilities in public issues, pull requests or discussions.

Use GitHub private vulnerability reporting instead: open the [Security tab](https://github.com/nlemoine/acf-country/security) of the repository and choose "Report a vulnerability", or go directly to https://github.com/nlemoine/acf-country/security/advisories/new.

Please include:

- the affected version of ACF Country, WordPress, ACF and PHP;
- a description of the vulnerability and its impact;
- steps to reproduce it, ideally with a minimal proof of concept.

You can expect an acknowledgement of your report, and a fix and coordinated disclosure once the issue is confirmed.
